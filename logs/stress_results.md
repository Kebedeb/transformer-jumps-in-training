## 6. Rule ambiguities

1. Precursor rule for 3 seeds. docs/hypothesis.md says “in all but one seed (4 of 5, or 3 of 4)”. For n = 3 this can be read as (A) all but one = 2 of 3, or (B) all 3 of 3, because the two examples given both require at least 75% of seeds and 2 of 3 is 67%. Both readings are reported in sections 4 and 5; neither is chosen. If a run has no jump, n is the number of jump runs, so the readings become 1 of 2 and 2 of 2; whether a no-jump run should instead count as a failing seed out of 3 is also not specified.
2. “Inconclusive: a signal fails by one seed” for n = 3: under reading A this is 1 of 3 qualifying, under reading B 2 of 3. Cells that are one seed short: reading A: `residL_eff_rank` in grokking_s3_2L64, `residL_part_ratio` in grokking_s3_2L64; reading B: `residL_part_ratio` in induction_s4_lr1e3, `max attn_L*H*_prev_token` in induction_s4_lr1e3, `residL_part_ratio` in icl_s4_lr3e4.
3. The pre-registration lists checkpoint intervals of 10 for induction and ICL and 100 for grokking. The ICL S4 config checkpoints every 20 steps. The main analysis code takes the interval from the median spacing of signals.csv, so the ICL S4 minimum lead is max(40, 0.05 × t50). This affects the minimum lead only when 0.05 × t50 < 40, i.e. t50 < 800; ICL S4 t50 values: seed 201 2120, seed 202 2360, seed 203 2420. No alternative interval was run.
4. The pre-registration does not say how S3/S4 outcomes enter the decision rules (Supports / Partial / Refutes / Inconclusive). No overall label is derived here.
5. The pre-registration does not define a comparison between stress and main configs. Section 5 uses “precursor in both batches” (deviation 1) as the main-config status; this choice is listed in section 7.

## 7. Implementation choices

1. Runs are matched by directory suffix `-<experiment_name>` and verified against `experiment_name`, `task.name` and `seed` (201-203) in config.json; `_INCOMPLETE` directories are ignored. The script stops before analysis if any run is missing, incomplete (final step < train_steps, missing or zero-byte checkpoints) or lacks signals.csv.
2. t50 = stays-above 0.5 on metrics.csv (`stays_above_step`, jump_detection.py), with the task's main metric (induction `heldout_acc`, ICL `fresh_map_acc`, grokking `val_acc`). It is cross-checked against the same column of signals.csv; disagreements are listed in section 8 and metrics.csv is used. Runs with no t50 are reported as “no jump” and their signals are not analysed.
3. Layer convention, as in the main analysis: L = `model.n_layers` from config.json and the final residual is `resid{L}`. All three stress configs have 2 layers, so signals 2-4 use `resid2_*` (for S3 grokking this differs from main grokking, which uses `resid1_*`). Signal 5 averages and signal 6 maxes over every `attn_L<l>H<h>_*` column, i.e. all heads in both layers.
4. Onset, lead, minimum lead, direction and qualification are computed by `precursor_analysis.analyse` with the pre-registered defaults (centered 5-checkpoint rolling median, reference window 5-30% of t50, 3 × 1.4826 × MAD band, minimum lead max(2 × interval, 0.05 × t50)). The checkpoint interval is the median step spacing of signals.csv (10 induction S4, 20 ICL S4, 100 grokking S3).
5. Per-experiment verdicts use the same logic as `precursor_analysis.verdicts` (enough qualifying seeds and one direction among them) with the required count set by reading A (n − 1) or B (n); `verdicts` itself hard-codes n − 1, so the count is applied in this script.
6. The positive control `attn_max_pattern` is analysed for induction and ICL only, with the same onset rule.
7. Main-config comparison: batch 1 and batch 2 `_main` runs are loaded with `precursor_analysis.load_runs` and analysed separately with the defaults; batch-1 t50 is checked against logs/run_results.md and batch-2 t50 against section 3.1 of logs/confirmation_results.md. “Main dir” is shown only when both batches are precursors with the same direction.
8. Specificity is not assessed: the C1/C2 controls were run on the main configs only.
9. Figures follow the confirmation figures: 2 × 3 panels (the six signals), x = (step − t50)/t50, y = smoothed signal − the run's reference median m, dotted line at t50, one colour per seed. No-jump runs are not plotted (no t50).
10. Only the pre-registered defaults were run; no other signals or parameters were tried.
